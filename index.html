Peephole flags macros, active scripts and automatic network requests — the behaviours behind most document-borne attacks. It is a helpful first look, not a full antivirus or a guarantee: a file called “safe” has no such behaviours in the parts Peephole can read, but always weigh where a file came from. Your file is checked entirely in your browser and is never uploaded; the only thing ever sent is an anonymous +1 to the shared counter.
